# 🏰 اِبْنِ ساحة معركتك الخاصة!

### كيف تعمل هذه اللعبة ثلاثية الأبعاد — وكيف تُطوِّرها **أنت**

دليلٌ وُدّيّ للأطفال الفضوليين 🎮
*مصنوعة بالبرمجة. لا حاجة لِخِبرة سابقة.*

---

## ما هذه اللعبة؟ 🎮

دافِع عن **أبراجك الثلاثة**. أنزِل **بطاقات** — فُرسان، تنانين، سَحَرة — على
أرض معركة يقسِمها **نهر** وعليه **جِسْران**.

- أنفِق **الإكسير** (طاقة بنفسجية) لِتلعب البطاقات
- تسير الجنود وتُقاتِل وحدها
- تستمر المباراة **٣ دقائق** ← أسقِط الأبراج لِتكسب **التيجان** 👑
- دمِّر **برج المَلِك** للعدو = فوزٌ فوري!

كل **الرسومات والأصوات أصلية**، مصنوعة من أشكال بسيطة وأصوات الحاسوب.

---

## الساحة ثلاثية الأبعاد التي تبنيها 🏟️

كل ما تراه مرسوم من **أشكال بسيطة** (مكعبات، كُرات، أقماع): مساران، نهر،
جِسْران، و٣ أبراج لِكُلِّ جانب — حتى الجنود والثلج والقمر كلها كود! 🌙

## السِّرُّ الكبير: عَقْل 🧠 + جَسَد 🦾

**أهمُّ فكرة** في اللعبة كلها:

| العَقْل (القواعد) | الجَسَد (ما تراه وتسمعه) |
|---|---|
| صِحّة الفارس | كيف يبدو الفارس |
| مَن يُهاجِم مَن | حركة ضربة السيف |
| مَن يفوز | موسيقى النصر |

مثل **الشطرنج**: القواعد نفسها سواء كانت القطع خشبًا أو زجاجًا أو على الهاتف.
نفصِل بين **القواعد** و**الصور** — فيُصبِح إصلاح اللعبة وتطويرها أسهل. 🌱

## البطاقة مُجرَّد قائمة حقائق 🃏

```typescript
knight: {

    hitSpeed: 1.2,    // الثواني بين الضربات

```

غيِّر `maxHp: 1400` ← `maxHp: 5000` فيُصبِح الفارس دبّابةً خارقة! 💪

## نبضة قلب المعركة 💓

اللعبة مثل **دفتر رسوم متحرِّكة** — صور كثيرة في الثانية. كل صفحة **نبضة
(tick)** تعمل ~٣٠ مرّة في الثانية في `sim.ts`:

```typescript
export function tick(state, dt) {
  // 1. أعطِ اللاعِبَين إكسير
  // 2. كل وحدة: جِد هدفًا، اِمشِ، هاجِم
  // 3. حرِّك السهام وكُرات النار
  // 4. احذِف ما ماتت صِحّتُه
  // 5. تحقَّق: هل فاز أحد؟
}
```

`dt` = الوقت منذ آخر نبضة. الحاسوب البطيء يخطو خطواتٍ **أقلّ وأكبر**، والسريع
خطواتٍ **كثيرةً صغيرة** — والجميع يقطع **المسافة نفسها**. 💬 كَـ**الكُتيِّب
المتحرّك**: قلِّبه بِبطءٍ أو بِسرعة، تبقى القصّة نفسها. ⏱️

---

## كيف تختار الوحدة قِتالها؟ 🎯

في كل نبضة، تسأل كل وحدة:

1. **"مَن هدفي؟"** (عادةً أقرب عدو)
2. **"هل أنا قريب كفايةً؟"** ← **نعم:** اِهجُم 💥 **لا:** اِقترِب 🚶

أضَفْنا **التمسُّك بالهدف**: ما إن تبدأ الوحدة *القتال*، تستمر فيه — ولا
تتشتَّت بعدوٍّ جديد. 🐶➡️🎯

```typescript
if (current && gap(e, current) <= e.attackRange) {
  return current; // ابقَ عليه — لا تتشتَّت!
}
```

## 🔢 رياضيات: كم تبعُد؟

في كل نبضة يسأل الجندي: *"كم يبعُد عدوّي؟"* والجواب هو **نظرية فيثاغورس** التي
تتعلّمها في المدرسة! 📐

```typescript
function distance(a, b) {
  return Math.hypot(a.x - b.x, a.y - b.y); // √(dx² + dy²)
}
```

الساحة شبكةٌ من النقاط **(x, y)**. والمسافة المستقيمة هي **الوتر** في مثلثٍ
قائم — `dx` أُفُقيًّا و`dy` رأسيًّا. 🔺

*رياضيات حقيقية تُستخدَم آلاف المرّات كل ثانية!*

---

## 🏃 فيزياء: كيف يتحرّك الجندي؟

لِيتحرّك، نرسم **سهمًا** (يُسمّى *مُتَّجِهًا*) من الجندي إلى هدفه، ونُصغِّره إلى
طولٍ **١** (*توحيد الطول*)، ثم نخطو على امتداده:

```typescript
const d = distance(e, goal);
e.x += (goal.x - e.x) / d * speed * dt; // خطوة صغيرة كل نبضة
e.y += (goal.y - e.y) / d * speed * dt;
```

**الموضع = الموضع + الاتجاه × السرعة × الزمن** ⏱️

💬 تخيّل **بوصلةً وخطوات**: *الاتجاه* (السهم المُصغَّر) يدلّ على الطريق،
و*السرعة × الزمن* تُحدِّد كم تخطو في هذه النبضة. 🧭

## 🧱 فيزياء: التصادُم والارتداد والجُدران

أفكار فيزيائية حقيقية داخل اللعبة:

- **تصادُم لطيف** 🤝 — لا يقف جنديّان في النقطة نفسها، فيتدافعان بِرفق. والعملاق
  الكبير يدفع الهيكل الصغير أكثر مما يدفعه الصغير.
- **الارتداد** 💥 — مُطلِقة المفرقعات *ترتدّ للخلف* بعد الإطلاق. هذا **قانون
  نيوتن الثالث**: لِكُلِّ دفعٍ دفعٌ مساوٍ مُعاكِس!
- **جُدرانٌ خفيّة** 🚧 — اكتشفنا مرّةً أن الجنود يرتدّون **خارج حافة** الساحة!
  فأضَفْنا جُدرانًا تمنع أي جسمٍ من مغادرتها. 🧯

*اكتشاف ذلك وإصلاحه عملٌ بوليسيّ حقيقي — تنقيح الأخطاء!* 🕵️

## 🔁 برمجة: الحَلقات والوصفات

فكرتان تُشغِّلان كل شيء:

- **الحَلقة** تُؤدّي العمل نفسه لِـ*كل* عنصر:
  > "**لِكُلِّ** جندي: ابحث عن هدف، تحرّك، هاجِم."
- **الدالّة** **وصفةٌ** تُسمّيها مرّةً وتُعيد استخدامها للأبد —
  `distance(...)` و`tick(...)` و`moveToward(...)`.

```typescript
for (const troop of allTroops) {
  actEntity(troop, dt);   // نفس الوصفة على كل واحد
}
```

تكتب الوصفة **مرّة**، فيُكرِّرها الحاسوب **ملايين** المرّات. 🔁

## 🏛️ معماريّة: العَقْل يُنادي والجَسَد يُصغي

كيف تتكلّم القواعد مع الصُّوَر **دون** أن تختلطا؟ بِـ**الأحداث** — رسائل صغيرة
يُنادي بها العَقْل بصوتٍ عالٍ: 📢

```typescript
state.events.push({ type: "crown", winner: "player" }); // 🧠 "سقط برج!"
```

و**الجَسَد** يُصغي ويتفاعل:

- 👂 الأُذنان ← شغِّل صوت *التاج* 🔔
- 👀 العينان ← هُزّ الكاميرا وأظهِر 👑

العَقْل لا يرسم ولا يُصدِر صوتًا، والجَسَد لا يعرف القواعد — هما فقط
**يتبادلان الرسائل**. تلك معماريّةٌ نظيفة. 🧩

💬 كَـ**الحَكَم**: الصافرة تصرخ *"هدف!"* فقط — واللاعبون والجمهور يُقرِّرون كيف
يحتفلون. 🎉

## 🎲 لا نَرد ولا ساعة = نفس المباراة كل مرّة

العَقْل **لا** يرمي نردًا حقيقيًّا ولا ينظر إلى الساعة الحقيقية. وحين يحتاج
"عشوائيّة" يستخدم **بذرة** — رقمَ بدايةٍ يصنع *النتائج نفسها* دائمًا:

```typescript
const rng = mulberry32(42); // البذرة 42 → نفس "العشوائية" كل مرّة
```

يُسمّى هذا **الحَتميّة** — كَـ**وصفة طبخ**: نفس المكوّنات والخطوات ← **نفس
الكعكة** في كل مرّة. 🎂 نفس الحركات ← **نفس المعركة**. هذا يجعل الأخطاء سهلة
**التكرار**… ويُشغِّل اللعب الجماعي 👇

---

## 🌐 اللعب الجماعي: كيف تعمل "الغرفة"؟

طفلان، هاتفان، **معركةٌ واحدة**. كيف تبقى الشاشتان متطابقتين؟

- يُنشئ كل لاعبٍ **غرفة** أو ينضمّ إليها بِرمزِ حيوانٍ سرّي 🦊
- الغرفة **ساعي بريدٍ** صغير — تنقل **الحركات** فقط
  ("لعِب فارسًا عند الجِسر الأيسر")، لا اللعبة كلها
- يُشغِّل الهاتفان **العَقْلَ الحَتميّ نفسه** **خطوةً بخطوة** متزامنين 🔒

💬 كَطفلَين يُؤدّيان **الرقصة نفسها** بينما **مُنادٍ** يصيح بالخطوات: الغرفة
هي المُنادي، تنقل الحركات فقط. ولأن العَقْل بلا نَردٍ ولا ساعة، يصنع الهاتفان
**المباراة نفسها** — لا فيديو! 📨✨

---

## 🤖 ذكاء اصطناعي: كيف يُفكِّر الخصم؟

البوت في `bot.ts` يتبع **سُلَّم أولويّات** كل ثانية — وأوّل ما يُناسب يفعله:

1. 🎯 **تعويذة** على تجمُّعٍ مُكتظّ من جنودي (إن كان يستحقّ الإكسير)
2. 🛡️ **دِفاع** — ردٌّ على المُهاجِم (يَستدرِج الدبّابة بِـ*مبنى*!)
3. 🏦 **ادّخار** — يُنزِل جامع الإكسير حين يأمَن ويمتلئ
4. ⚔️ **هجوم** — يتقدّم بِدبّابةٍ ثم يُرسِل **الدعم** إلى مسارها

جعَلْناه مؤخّرًا **أذكى**: صار يختار مسارًا *واحدًا* ويضغط أقوى في الإكسير
المُضاعَف، بدل تشتيت الجنود في كل مكان. 🧠

## 🌀 رياضيات في كل مكان: نِسَب وزوايا وحَلَزونات

- **النِّسَب المئوية** — كل *مستوى* للبطاقة يُضيف **١٠٪**: `1 + 0.1 × (level − 1)` 📈
- **الاحتمال** — يرمي البوت قطعةَ نقدٍ لِيختار مسارًا: `rng() < 0.5` 🪙
- **الزوايا والحَلَزونات** — يظهر السِّربُ على **حَلَزونٍ بالزاوية الذهبية**
  (≈١٣٧٫٥°)، نفس نمط بذور **عبّاد الشمس**! 🌻

```typescript
const a = i * 2.399963;          // الزاوية الذهبية (راديان)
x = Math.cos(a) * r;  y = Math.sin(a) * r;   // ترتيبٌ مُتساوٍ جميل
```

الطبيعة والألعاب تستخدمان **الرياضيات نفسها**. 🤯

## أهمُّ عادة: الاختبار أولًا! ✅

**أحمر 🔴 ← أخضر 🟢 ← تحسين 🔵**

1. 🔴 اكتب اختبارًا لِما *تُريد* — يَفشَل (لم تبنِه بعد)
2. 🟢 اكتب أبسط كودٍ يجعله ينجح
3. 🔵 نظِّفه مع بقاء الاختبار أخضر

```typescript
it("the firecracker hops backward after firing", () => {
  const startY = firecracker.y;
  run(battle, 1.5);                       // اِترك الوقت يمرّ
  expect(firecracker.y).toBeGreaterThan(startY + 1); // تحرَّكت للخلف!
});
```

في هذه اللعبة **أكثر من ٢٤٠** فحصًا تعمل طوال الوقت! 🎉
