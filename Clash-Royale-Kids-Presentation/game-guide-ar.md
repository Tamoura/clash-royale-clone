# 🏰 اِبْنِ ساحة معركتك الخاصة!
### دليل الأطفال لِفَهم كيف تعمل هذه اللعبة — وكيف يُمكِنُك **أنت** أن تُطوِّرها

> لعبة معارك ثلاثية الأبعاد (3D) مصنوعة بالبرمجة. يشرح هذا الدليل كيف بُنِيَت
> اللعبة، ويُريك أجزاءً حقيقية من الكود (الشيفرة البرمجية)، ويُعطيك أفكارًا
> (وأوامر جاهزة للذكاء الاصطناعي) لِتُضيف بطاقاتك وأصواتك وساحاتك الخاصة.

> **لِمَن هذا الدليل؟** للأطفال الفضوليين (في عُمر الصف السادس تقريبًا) الذين
> يُريدون معرفة كيف تُصنَع لعبة فيديو حقيقية — لا حاجة لِخِبرة سابقة.

## الشريحة ١ — ما هذه اللعبة؟ 🎮

لاعبان (أو أنت ضِدّ الحاسوب) يُدافِع كلٌّ منهما عن **ثلاثة أبراج**.
تُنزِل **بطاقات** — فُرسان، تنانين، سَحَرة، عمالقة — على أرض معركة يقسِمها
**نهر** عليه **جِسْران**.

- تسير جنودك نحو العدو وتُقاتِل.
- تُنفِق **الإكسير** (طاقة بنفسجية تمتلئ ببطء) لِتلعب البطاقات.
- تستمر المباراة **٣ دقائق**. أسقِط الأبراج لِتكسب **التيجان**.
- دمِّر **برج المَلِك** للعدو، أو اِجمَع أكثر تيجان عند انتهاء الوقت — **تفوز!** 👑

كل **الرسومات أصلية** مصنوعة من أشكال بسيطة (مكعبات وكُرات وأقماع)، وكل
**الأصوات يصنعها الحاسوب** — دون نسخ صور أو موسيقى أحد.

*أرض المعركة ثلاثية الأبعاد — أبراج ونهر وجِسْران وجنود، كلها مرسومة بالكود.*

## الشريحة ٢ — السِّرُّ الكبير: لِكُلِّ لعبة "عَقْل" و"جَسَد" 🧠➕🦾

هذه **أهمُّ فكرة** في اللعبة كلها. تذكَّرها جيدًا!

| العَقْل (القواعد) | الجَسَد (ما تراه وتسمعه) |
|---|---|
| كم صِحَّة الفارس | كيف *يبدو* الفارس |
| مَن يُهاجِم مَن | حركة ضربة السيف |
| مَن يفوز | موسيقى النصر |

**لماذا نفصِل بينهما؟** فكِّر في لعبة لوحية مثل الشطرنج:
- **قواعد** الشطرنج هي نفسها سواء لعبتَ بقطع خشبية أو زجاجية أو على الهاتف.
- أمّا **القطع** فيُمكِن أن تبدو بأيِّ شكل.

في لعبتنا، **العَقْل** هو كود يقوم بالحسابات فقط — ولا يرسم شيئًا أبدًا.
أمّا **الجَسَد** فيقرأ العَقْل ويرسم الصور الجميلة. فَصْلُهما يجعل اللعبة
أسهل في الإصلاح والاختبار والنُّموّ. 🌱

## الشريحة ٣ — مِمَّ صُنِعَت اللعبة؟ 🛠️

| الأداة | ماذا تفعل | المعنى المُبسَّط |
|---|---|---|
| **TypeScript** | لغة البرمجة | مثل لغتنا، لكن للحاسوب — وتُسمّي كل شيء حتى تُقِلّ أخطاءك |
| **Three.js** | ترسم الرسومات ثلاثية الأبعاد | "مُعلِّم الفن" الذي يُحوِّل الأرقام إلى أشكال 3D على الشاشة |

| **Vite** | تُشغِّل اللعبة | "زِرّ التشغيل" الذي يبدأ كل شيء على حاسوبك |

اللعبة كلها تعمل **داخل متصفِّح الإنترنت** (مثل Chrome) — دون متجر تطبيقات!

## الشريحة ٤ — خريطة المشروع 🗺️

الكود مُقسَّم إلى مُجلَّدات (folders)، لِكُلٍّ منها مَهمّة واحدة:

```
src/
├── game/        ← 🧠 العَقْل: القواعد والحسابات (بلا صور!)
│    ├── cards.ts      أرقام كل بطاقة (الفارس، العملاق، التنين…)
│    ├── sim.ts        "نبضة القلب" التي تُحرِّك المعركة للأمام
│    ├── battle.ts     أرض المعركة والأبراج والإكسير
│    └── bot.ts        تفكير الخصم (الحاسوب)
│
├── render3d/    ← 🦾 الجَسَد (العيون): يُحوِّل العَقْل إلى صور 3D
│    ├── characters3d.ts   يبني كل شخصية من أشكال ثلاثية الأبعاد
│    └── scene3d.ts        الكاميرا والإضاءة والعالَم 3D كله
│
├── audio/       ← 🦾 الجَسَد (الأذنان): يصنع كل الأصوات
├── net/         ← 🌐 يُتيح للاعِبَين حقيقِيَّين اللعب عبر الواي‑فاي
└── main.ts      ← 🔌 الغِراء الذي يربط كل شيء معًا
```

👈 لاحِظ: مُجلَّد **game/** لا يرسم ولا يُشغِّل أيَّ شيء. هذا هو سِرُّ الشريحة ٢!

## الشريحة ٥ — البطاقة ما هي إلا قائمة من الحقائق 🃏

افتح ملف `src/game/cards.ts` فتجد كل بطاقة مكتوبة كقائمة بسيطة من الحقائق.
هذا هو **الفارس (Knight)**:

```typescript
knight: {
  name: "Knight",
  cost: 3,            // يكلِّف 3 إكسير لِلَّعِب
  count: 1,           // تحصل على فارس واحد
  unit: unit({
    maxHp: 1400,      // الصِّحَّة: كم ضربة يتحمَّل
    damage: 160,      // قوة ضربته
    hitSpeed: 1.2,    // الثواني بين كل ضربة
    attackRange: 0.8, // قصير جدًا = يجب أن يقترب (قتال مُلاصِق)
    speed: "medium",  // سرعة مَشيه
  }),
}
```

هذا كل شيء! البطاقة **مُجرَّد أرقام وكلمات**. غيِّر `maxHp: 1400` إلى
`maxHp: 5000` فيُصبِح الفارس فجأةً دبّابةً خارقة. 💪

<img src="img/deck-builder.png" width="280" alt="بانِي المجموعة يعرِض كل البطاقات." />

*مجموعة البطاقات — كل بطاقة هنا، ومنها المُفرقِعة والرامي السحري اللذان أضَفْناهما.*

## الشريحة ٦ — نبضة قلب المعركة 💓

لعبة الفيديو تُشبِه **دفتر الرسوم المتحرِّكة (flipbook)**: ترسم صورة مختلفة
قليلًا مرّات كثيرة في الثانية، فترى عيناك حركةً.

كل "صفحة" نُسمّيها **tick** (نبضة). نحو ٣٠ مرة في الثانية، يُشغِّل العَقْل
هذه الدالة `tick` في ملف `src/game/sim.ts`:

```typescript
export function tick(state, dt) {
  // 1. أعطِ كلا اللاعِبَين قليلًا من الإكسير
  // 2. لِكُلِّ وحدة: جِد هدفًا، اِمشِ نحوه، هاجِم
  // 3. حرِّك السهام وكُرات النار الطائرة
  // 4. احذِف أيَّ شيء وصلت صِحّتُه إلى الصِّفر
  // 5. تحقَّق: هل فاز أحدٌ ما؟
}
```

`dt` تعني **"فَرْق الوقت" (delta time)** — كم مرّ من الوقت منذ النبضة السابقة.
استخدام `dt` يُبقي اللعبة بنفس السرعة على حاسوب سريع **و**حاسوب بطيء. ⏱️

## الشريحة ٧ — كيف تعرف الوحدة مَن تُقاتِل؟ 🎯

في كل نبضة، تسأل كل وحدة سؤالين:

1. **"مَن هدفي؟"** (عادةً أقرب عدوٍّ أو برج)
2. **"هل أنا قريب بما يكفي لِأضرِبه؟"**
   - **نعم** ← اِهجُم! 💥
   - **لا** ← اِخطُ خطوةً للاقتراب. 🚶

أضَفْنا مؤخَّرًا قاعدةً ذكيّة اسمها **التمسُّك بالهدف**: ما إن تبدأ الوحدة
*قتال* شيءٍ ما، فإنها **تستمر** في قتاله — حتى لو ظهر عدوٌّ جديد أقرب. (قبلها
كانت الوحدات تتشتَّت بسهولة، مثل جَرْوٍ يُطارِد كل سِنجاب! 🐶)

```typescript
// إذا كنتُ بالفعل ضمن مدى هدفي، فابقَ عليه.
if (current && gap(e, current) <= e.attackRange) {
  return current; // لا تتشتَّت!
}
```

## الشريحة ٨ — بطاقتان بَنَيناهما، خطوةً بخطوة ✨

أضَفْنا بطاقتين جديدتين تمامًا. احتاجت كلٌّ منهما **قُدرةً خاصّة جديدة** لم
تكن موجودة في اللعبة من قبل:

### 🧨 المُفرقِعة (Firecracker)
- تُطلِق صاروخًا يُحدِث **انفجارًا مُنتشِرًا** (يُصيب عدّة أعداء).
- لها **ارتداد (recoil)** — تقفز إلى **الخلف** بعد كل طلقة، مثل رَكْلة المُفرقِعة الحقيقية!

### 🏹 الرامي السحري (Magic Archer)
- يُطلِق سهمًا واحدًا **يخترِق** — يطير في خط مستقيم ويُصيب **كل** عدوٍّ يمرّ
  به، لا الأول فقط.

وهذه بطاقة المُفرقِعة (لاحِظ `recoil` و`splashRadius`):

```typescript
firecracker: {
  name: "Firecracker",
  cost: 3,
  unit: unit({
    maxHp: 140,         // ضعيفة جدًا — اِحمِها!
    damage: 130,
    hitSpeed: 3,        // إعادة تعمير بطيئة
    attackRange: 6,     // تُطلِق من بعيد
    speed: "fast",
    targetsAir: true,   // تستطيع إصابة الطائرين
    splashRadius: 1.4,  // الشرر ينتشر
    recoil: 2,          // تقفز خطوتين للخلف بعد الإطلاق 🆕
  }),
}
```

## الشريحة ٩ — أهمُّ عادة: الاختبار أولًا! ✅

يستخدم المبرمِجون الحقيقيون حيلةً اسمها **التطوير المُوجَّه بالاختبار (TDD)**.
الترتيب: **أحمر ← أخضر ← تحسين**.

1. 🔴 **أحمر:** أولًا، اكتب اختبارًا صغيرًا يقول ما *تُريده*. شغِّله — فيَفشَل
   (أحمر)، لأنك لم تبنِه بعد. وهذا جيّد!
2. 🟢 **أخضر:** الآن اكتب أبسط كودٍ يجعل الاختبار **ينجح** (أخضر).
3. 🔵 **تحسين:** نظِّف كودك لِيُصبِح مُرتَّبًا، مع بقاء الاختبار أخضر.

وهذا اختبار حقيقي للمُفرقِعة:

```typescript
it("the firecracker hops backward after firing", () => {
  // نضع مُفرقِعةً وعدوًّا على الخريطة...
  const startY = firecracker.y;
  run(battle, 1.5); // نترك 1.5 ثانية تمرّ
  // ...ونتحقَّق أنها تحرَّكت للخلف!
  expect(firecracker.y).toBeGreaterThan(startY + 1);
});
```

كتابة الاختبار أولًا مثل الاتفاق على **قواعد اللعبة قبل أن نلعب**، حتى يتَّفِق
الجميع على معنى "الفوز". في هذه اللعبة **أكثر من ٢٤٠** فحصًا صغيرًا تعمل
طوال الوقت! 🎉

## الشريحة ١١ — البرمجة بمساعدة الذكاء الاصطناعي 🤖

يُمكِنك أن تطلب من مساعِد ذكاء اصطناعي (مثل Claude Code) أن يُساعِدك في بناء
أشياء جديدة. السِّرّ هو أن **تصِف بالضبط ما تُريد**، كأنك تُعطي توجيهات لِروبوت.
وهذه أوامر حقيقية يُمكِنك نسخها وتجرِبتها:

**🃏 أضِف بطاقةً جديدة**
> "أضِف بطاقةً جديدة اسمها **كلب الحِمَم (Lava Hound)** تطير، صِحّتها 3000،
> تُهاجِم المباني فقط، وتتحرَّك ببطء. وعندما تموت، اجعلها تنفجِر إلى 6 جِراء
> حِمَم صغيرة. اتبِع نفس أسلوب باقي البطاقات، واكتب اختبارًا أولًا."

**🎨 غيِّر شكل شيءٍ ما**
> "غيِّر أرضية الساحة من الحجر الرملي إلى عشب أخضر فيه زهور."

**✨ أضِف قُدرةً جديدة**
> "اجعل كُرة نار الساحر تترك حلقة نار صغيرة على الأرض لمدّة 3 ثوانٍ تُؤذي مَن
> يمشي فيها من الأعداء."

**🔊 أضِف صوتًا**
> "شغِّل صوت بوق مَرِح عندما أُدمِّر برج العدو."

**💡 نصيحة:** اطلب دائمًا من الذكاء الاصطناعي أن **يكتب اختبارًا أولًا**، وأن
**يفصِل بين العَقْل والجَسَد** (الشريحة ٢). هكذا يعمل المُحترِفون!

## الشريحة ١٢ — تحسينات المستقبل: جاء دورك! 🌟

اللعبة مُجرَّد بداية. وهذه أفكار لِتجعلها أروع. اختَر ما يُحمِّسك!

**🟢 الأسهل (مشاريع أولى رائعة)**
- اِختَرِع **٣ بطاقات جديدة** بأسماء وأرقام من عندك.
- اصنع **ساحة بطابَع جديد**: حِمَم، أو ثلج، أو فضاء، أو تحت الماء.
- أضِف **أصوات نصر وهزيمة** أو موسيقى خلفية.
- اجعل بطاقةً تترك **أثرًا بألوان قوس قُزَح** أثناء المشي.

**🟡 المتوسط (تحدٍّ مُمتِع)**
- أضِف **تعويذة جديدة**، مثل إعصار يَسحَب الأعداء معًا.
- اصنع **وضع "المتاعب المزدوجة"** حيث تظهر كل بطاقة مرّتين.
- اجعل خصم الحاسوب **أذكى** في الدفاع.
- أضِف **شاشة مجموعة البطاقات** تعرِض كل ما فتحتَه منها.

**🔴 الأصعب (لِمُطوِّري الألعاب في المستقبل!)**
- أضِف **رموزًا تعبيرية (emotes)** لِيُرسِل اللاعِبون وجوهًا مُضحِكة في المعركة.
- اِبنِ **لوحة مُتصدِّرين** تتذكَّر أعلى النتائج.
- حوِّلها إلى **تطبيق هاتف** لِتلعب على جهاز لوحي.
- صمِّم وضع **٣ لاعبين أو معارك فِرَق**.
